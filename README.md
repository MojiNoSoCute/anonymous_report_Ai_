# NPRU Sentinel - Anonymous Report Portal (TrustLine)
ระบบแจ้งเบาะแสและจัดการข้อมูลอย่างเป็นระบบ ปลอดภัย และเข้ารหัส (Nakhon Pathom Rajabhat University)

---

## 📌 บทนำ (Introduction)
**NPRU Sentinel (TrustLine)** เป็นระบบเว็บแอปพลิเคชันสำหรับรับแจ้งเรื่องร้องเรียน เบาะแส และปัญหาภายในมหาวิทยาลัยราชภัฏนครปฐม โดยให้ความสำคัญสูงสุดกับ **ความปลอดภัย ความเป็นนิรนาม (Anonymity) และการปกป้องตัวตนของผู้แจ้ง** พร้อมด้วยระบบ **AI Smart Assistant (Gemini 3.6 Flash)** ที่ช่วยคัดกรองหมวดหมู่ ประเมินความเร่งด่วน และสรุปข้อมูลอัตโนมัติ

---

## ✨ ฟีเจอร์หลัก (Key Features)

1. **🔒 แจ้งเบาะแสนิรนาม 100% (100% Anonymous Reporting)**
   - ไม่ต้องลงชื่อเข้าใช้ ไม่เก็บ IP Address หรือข้อมูลระบุตัวตน
   - แนบไฟล์หลักฐาน (รูปภาพ, PDF, เอกสาร) พร้อมระบบเข้ารหัสข้อมูล
   - เข้ารหัส PIN 6 หลักด้วย SHA-256 เพื่อใช้เข้าถึงรายงาน

2. **🤖 AI Smart Assistant (Gemini 3.6 Flash)**
   - วิเคราะห์ข้อความคำอธิบายภาษาไทยแบบเรียลไทม์
   - จัดหมวดหมู่เรื่องร้องเรียนอัตโนมัติ 7 หมวดหมู่ (Harassment, Fraud, Academic, Technical, Safety, Compliance, Teaching)
   - ประเมินระดับความเร่งด่วนเบื้องต้น พร้อมเหตุผลประกอบและคำสำคัญ (Keywords)
   - **ระบบควบคุมสิทธิ์:** ล็อกการปรับระดับความเร่งด่วน ให้เฉพาะเจ้าหน้าที่ (Admin) ผู้รับผิดชอบคดีเป็นผู้ปรับเปลี่ยนได้เท่านั้น

3. **🔍 ติดตามสถานะและการสนทนาลับ 2 ทาง (Status Tracking & 2-Way Secure Chat)**
   - ผู้แจ้งใช้ **Report ID** (เช่น `TL-2024-X89K`) + **PIN 6 หลัก** ในการติดตามสถานะ
   - สามารถแชทคุยกับเจ้าหน้าที่ผู้รับผิดชอบคดีได้แบบเรียลไทม์โดยยังคงสถานะนิรนาม

4. **📋 ระบบจัดการคดีสำหรับเจ้าหน้าที่ (Admin & Staff Case Manager)**
   - แดชบอร์ดตรวจสอบเรื่องร้องเรียน คัดกรองตามหมวดหมู่ ความเร่งด่วน และสถานะ
   - การปรับเปลี่ยนสถานะคดี (รับเรื่อง, กำลังตรวจสอบ, ดำเนินการทางวินัย, ปิดเรื่อง)
   - สิทธิ์เฉพาะ Admin ในการแก้ไขและทบทวนระดับความเร่งด่วน (Urgency Level)
   - ระบบบันทึกประวัติการตรวจสอบ (Audit Trail / Logs) ป้องกันการแก้ไขข้อมูลโดยพลการ

5. **📊 แดชบอร์ดสถิติและการวิเคราะห์ (Analytics Dashboard)**
   - กราฟสรุปสถิติเรื่องร้องเรียนแยกตามหมวดหมู่ ความเร่งด่วน และแนวโน้มรายเดือน
   - แผนภูมิวิเคราะห์จุดเสี่ยงของพื้นที่ภายในมหาวิทยาลัย

6. **🐍 รองรับสถาปัตยกรรม 2 รูปแบบ (Dual Architecture Support)**
   - **Full-Stack Node.js (React + Vite + Express + Gemini AI SDK)** สำหรับการรันบน Cloud Run / AI Studio
   - **Python Flask + SQLite Backend (`app.py`, `schema.sql`)** สำหรับนำไป Deploy บน Python Server อิสระ

## 📖 คู่มือการใช้งาน (How to Use)

### 👤 1. สำหรับนักศึกษาและบุคคลทั่วไป (Whistleblower / General Public)

#### ขั้นตอนที่ 1: สร้างรายงานแจ้งเบาะแส (Submit a Report)
1. เข้าสู่หน้าหลักของระบบ เลือกแท็บ **"สร้างรายงานใหม่"**
2. เลือก **หมวดหมู่ปัญหา** (หรือให้ AI ช่วยเลือกให้อัตโนมัติ)
3. พิมพ์ **สถานที่เกิดเหตุ** และ **รายละเอียดเหตุการณ์** ให้ชัดเจน
4. เมื่อพิมพ์รายละเอียด ระบบ **AI Smart Assistant** จะประมวลผลคำอธิบาย และเลือกหมวดหมู่พร้อมประเมินระดับความเร่งด่วนให้ทันที
5. (ไม่บังคับ) แนบไฟล์รูปภาพ หรือเอกสารหลักฐาน
6. กดปุ่ม **"ส่งรายงานอย่างปลอดภัย (Encrypted Submit)"**
7. **⚠️ สำคัญมาก:** ระบบจะแสดง **รหัสรายงาน (Report ID)** และ **รหัส PIN ลับ 6 หลัก** ให้ทำการบันทึกหรือคัดลอกเก็บไว้ทันที (รหัส PIN จะไม่ถูกจัดเก็บแบบ Plaintext และไม่สามารถกู้คืนได้)

#### ขั้นตอนที่ 2: ติดตามสถานะและแชทกับเจ้าหน้าที่ (Track Status & Chat)
1. เลือกแท็บ **"ติดตามสถานะ"**
2. กรอก **รหัสรายงาน (Report ID)** และ **รหัส PIN 6 หลัก**
3. กดปุ่ม **"ตรวจสอบข้อมูลรายงาน"**
4. ระบบจะแสดงสถานะปัจจุบัน (เช่น รับเรื่องแล้ว, กำลังตรวจสอบ) พร้อมประวัติไทม์ไลน์
5. ผู้แจ้งสามารถพิมพ์ข้อความส่งหาเจ้าหน้าที่ หรือส่งหลักฐานเพิ่มเติมผ่านกล่องแชทลับได้ทันที

---

### 🛡️ 2. สำหรับเจ้าหน้าที่และผู้ดูแลระบบ (Admin / Staff)

#### ข้อมูลบัญชีผู้ใช้สำหรับทดสอบ (Default Test Accounts):
| บทบาท (Role) | Username | Password | สิทธิ์การเข้าถึง |
|---|---|---|---|
| **Admin (หัวหน้างาน)** | `admin` | `admin123` | จัดการทุกคดี, ปรับระดับความเร่งด่วน, ดูสถิติ, ดู Audit Logs |
| **Officer (เจ้าหน้าที่สอบสวน)** | `officer1` | `officer123` | ตรวจสอบคดี, แชทตอบกลับผู้แจ้ง, อัปเดตสถานะคดี |

#### ขั้นตอนการทำงานของเจ้าหน้าที่:
1. กดปุ่ม **"เจ้าหน้าที่เข้าสู่ระบบ"** ที่แถบเมนูด้านบนขวา
2. กรอก Username และ Password
3. เมื่อเข้าสู่ระบบแล้ว เมนูจะเปลี่ยนเป็น:
   - **จัดการรายงานทั้งหมด (Case Manager):**
     - ดูรายการเรื่องร้องเรียนทั้งหมด
     - กรองตามสถานะ ความเร่งด่วน หรือค้นหาด้วยคีย์เวิร์ด
     - กดเข้าไปดูรายละเอียดคดีเพื่ออ่านข้อความและไฟล์แนบ
     - **เปลี่ยนสถานะคดี (Status):** ปรับเป็น `รับเรื่องแล้ว`, `กำลังตรวจสอบ`, `ดำเนินการทางวินัย`, หรือ `ปิดเรื่องเรียบร้อย`
     - **ปรับระดับความเร่งด่วน (Urgency - เฉพาะ Admin):** ปรับเปลี่ยนเป็น `ปกติ (Low)`, `ปานกลาง (Medium)`, `สูง (High)`, หรือ `วิกฤต (Critical)`
     - ตอบแชทลับคุยกับผู้แจ้งเบาะแส
   - **สถิติ & สรุปผล (Analytics):** ดูภาพรวมและแนวโน้มเรื่องร้องเรียนเพื่อวางแผนป้องกัน

## 🛠️ วิธีการติดตั้งและรันระบบ (Installation & Setup)

### ทางเลือกที่ 1: รันด้วย Node.js (React + Vite + Express + Gemini AI)

#### ความต้องการของระบบ (Prerequisites)
- Node.js 18.0.0 หรือสูงกว่า
- npm หรือ bun

#### ขั้นตอนการติดตั้ง:
```bash
# 1. ติดตั้ง Dependencies ทั้งหมด
npm install

# 2. คัดลอกและตั้งค่า Environment Variables
cp .env.example .env
```

#### การตั้งค่า `.env`:
```env
# API Key สำหรับเชื่อมต่อ Gemini AI (รับได้จาก Google AI Studio)
GEMINI_API_KEY="AIzaSy..."

# URL ของระบบ
APP_URL="http://localhost:3000"
```

#### เริ่มต้นรันระบบ:
```bash
# รัน Development Server (Port 3000)
npm run dev

# หรือ Build สำหรับ Production
npm run build
npm start
```
เปิดเว็บเบราว์เซอร์แล้วเข้าไปที่ `http://localhost:3000`

---

### ทางเลือกที่ 2: รันด้วย Python (Flask + SQLite3)

โปรเจกต์นี้มีไฟล์ `app.py` และ `schema.sql` ให้พร้อมใช้งาน:

```bash
# 1. สร้างและเปิดใช้งาน Virtual Environment
python -m venv venv

# บน Linux / macOS:
source venv/bin/activate

# บน Windows:
venv\Scripts\activate

# 2. ติดตั้ง Dependencies
pip install flask flask-cors

# 3. รันเซิร์ฟเวอร์ Python
python app.py
```
เปิดเว็บเบราว์เซอร์แล้วเข้าไปที่ `http://localhost:5000`

## 🔐 สถาปัตยกรรมความปลอดภัย (Security Architecture)

1. **Zero-Knowledge PIN Verification:** รหัส PIN ถูก Hash ด้วยอัลกอริทึม SHA-256 ก่อนบันทึกลงฐานข้อมูล แม้กระทั่งผู้ดูแลฐานข้อมูลก็ไม่สามารถล่วงรู้รหัสผ่านเดิมได้
2. **Strict Role-Based Access Control (RBAC):** แยกระดับสิทธิ์ระหว่างผู้แจ้งทั่วไป (Guest), เจ้าหน้าที่สอบสวน (Officer) และผู้ดูแลระบบ (Admin)
3. **Admin Urgency Locking:** การประเมินความเร่งด่วนเริ่มต้นทำโดย AI และเปิดให้เฉพาะผู้ใช้ระดับ Admin แก้ไขเพื่อป้องกันการลดหย่อนระดับความสำคัญของคดี
4. **Server-Side AI Proxy:** ซ่อน `GEMINI_API_KEY` ไว้ที่ฝั่ง Server-side (`server.ts`) ไม่เปิดเผยไปยัง Browser ของผู้ใช้งาน
